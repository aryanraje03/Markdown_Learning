## Headings

Markdown has **6 heading levels**.

- `#` → biggest heading
- `######` → smallest heading

### Example

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
```

---

## Bold Text

Use two asterisks `**` or two underscores `__`.

### Example

```markdown
**this**
__this__
```

**Output:** **this**

---

## Italic Text

Use one asterisk `*` or one underscore `_`.

### Example

```markdown
*this*
_this_
```

**Output:** *this*

---

## Line Breaks

To move text to the next line:

- Use `<br>`
- Or leave two spaces at the end of a line

### Example

```markdown
Hello<br>
World
```

---

## Links

Use this format to add a link.

### Example

```markdown
[This is a link](https://www.youtube.com/@NeuralNine)
```

**Output:** [This is a link](https://www.youtube.com/@NeuralNine)

---

## Comments

Comments do not appear in the final output.

### Example

```markdown
[comment]: (This is my comment)
[//]: <> (This is also a comment)
```

---

## Images

Use this format to insert an image.

### Example

```markdown
![My Image](https://www.neuralnine.com/wp-content/uploads/2020/07/Design-ohne-Titel-3-1024x1024.png)
```

---

## Blockquotes

Use `>` before the text.

### Example

```markdown
> "My name is Trupti. I am learning Markdown."
```

**Output:**

> "My name is Trupti. I am learning Markdown."

---

## Unordered Lists

Use `-` or `*` to create bullet points.

### Example

```markdown
- One
- Two
- Three
- Four
```

**Output:**

- One
- Two
- Three
- Four

---

## Ordered Lists

Use numbers followed by a period.

### Example

```markdown
1. Hello
2. World
```

**Output:**

1. Hello
2. World

---

## Task Lists

Use:

- `- [ ]` for an unchecked task
- `- [x]` for a checked task

### Example

```markdown
- [ ] Task 1
- [ ] Task 2
- [x] Task 3
```

**Output:**

- [ ] Task 1
- [ ] Task 2
- [x] Task 3

---

## Quick Tip

Markdown is easy to learn. Start with:

- headings
- bold
- italic
- lists
- links

Once you get comfortable with these, writing README files becomes much easier!
